## Что умеет приложение

- Запись экрана Windows 10/11: весь экран, окно или прямоугольник
  (графический выбор с лупой и пиксельной подстройкой стрелками).
- Одновременная запись нескольких мониторов в отдельные файлы и
  горячее переключение источника без остановки записи.
- Веб-камера PiP-оверлеем: камера пишется параллельно и вкомпозитируется
  в выбранный угол итогового видео (позиция и размер настраиваются).
- Аудио: микрофон, системный звук или оба; опциональное шумоподавление
  микрофона (лёгкое/сильное, FFmpeg afftdn).
- Аппаратное кодирование: NVENC/AMF/QSV для H.264/HEVC и AV1
  (показываются только энкодеры, собранные в вашем FFmpeg), с
  автоматическим откатом на программные кодеки.
- Обратный отсчёт перед стартом записи (0–10 с, Esc — отмена).
- Эффекты курсора: подсветка и расходящиеся кольца при кликах
  (ЛКМ/ПКМ разными цветами) — попадают в запись.
- Постобработка: транскодирование, сжатие, обрезка тишины, GIF-превью,
  Whisper-транскрипция, авто-zoom по активности мыши, копирование в
  папку, webhook, плагины.
- Библиотека записей с миниатюрами, тегами и быстрыми действиями.
- Профили записи с импортом/экспортом.
- Управление из GUI, через REST API (с HMAC-webhook и WebSocket) и CLI.
- Планировщик задач записи (once/daily/weekly/interval/cron).
- Мастер первого запуска: сводка настроек и проверка готовности;
  поиск по настройкам на странице настроек.
- Надёжность: сегменты, восстановление после сбоев FFmpeg, мониторинг
  диска, проверка целостности файла и авторемонт.
- Двухъязычный интерфейс (русский/английский), темы, Windows 11 Mica.

## Поддерживаемая платформа

- Windows 10/11 (проект целевой только для Windows).
- Python 3.11+.
- FFmpeg должен быть доступен в `PATH`.

## Рекомендованный порядок начала

1. Прочитайте [Установка](Installation).
2. Выполните шаги из [Быстрый старт](Quick-Start).
3. При первом запуске пройдите мастер первичной настройки — он
   показывает сводку настроек и результат проверки готовности.
4. Настройте токен и порт по [Конфигурация и переменные окружения](Configuration-and-Environment).
5. Для интеграций перейдите в [REST API](API); для HTTPS-доступа из LAN —
   [гайд по TLS](https://github.com/chelslava/MIA-ScreenCapture/blob/main/docs/api-tls.md).
