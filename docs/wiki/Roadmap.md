# Стратегическая дорожная карта: MIA-ScreenCapture 2026+

Проект MIA-ScreenCapture имеет прочный фундамент (Windows Graphics Capture, FFmpeg, REST API). Для перехода в высшую лигу (конкуренция с Loom, OBS, ShareX, Camtasia) необходимо сфокусироваться на производительности, бесшовном шеринге и, самое главное, на **интеллектуальной обработке контента (AI)**.

Эта дорожная карта предлагает пошаговое превращение утилиты в "умного ассистента для скринкастинга".

## Фаза 1: Ядро, Производительность и Базовый UX (Q3-Q4 2026)
*Задача: Устранить узкие места, снизить потребление ресурсов и подготовить платформу для тяжелых модулей.*

- **Аппаратное ускорение кодирования (Hardware Encoding)**
  Автоопределение доступных GPU в системе и поддержка кодеков `hevc_nvenc` / `h264_nvenc` (NVIDIA), `h264_amf` / `hevc_amf` (AMD), `h264_qsv` / `hevc_qsv` (Intel). Снижение нагрузки на CPU до 1-5% при записи 4K/60FPS.
- **Архитектурная стабилизация (Техдолг API)**
  Внедрение `Idempotency-Key` для API-маршрутов (защита от двойного старта), отвязка от GUI-потока, хранение ключей в ОС (Windows Credential Manager).
- **Модернизация GUI**
  Внедрение компонентов в стиле **Windows 11 Mica/Acrylic**. Переработка плавающего виджета записи, инструменты быстрого рисования поверх экрана.

## Фаза 2: Глубокая интеграция ИИ (AI-First Features) (Q1-Q2 2027)
*Задача: Избавить пользователя от ручного монтажа и написания сопроводительных текстов. MIA-ScreenCapture должен понимать, что именно происходит на экране.*

- **Интеллектуальная обработка звука (Real-time AI Audio)**
  AI Шумоподавление (Noise Suppression) в реальном времени. Автоматическое выравнивание громкости голоса.
- **Smart Zoom (Авто-зум)**
  Анализ движения мыши и событий клика/ввода для генерации плавных наездов камеры.
- **Умная обрезка (Silence Removal)**
  Локальный анализ аудиодорожки (VAD). Автоматическое удаление пауз, вздохов и слов-паразитов ("э-э-э") из финального видео.
- **Privacy Blur (Размытие приватных данных)**
  Распознавание лиц, email-адресов, паролей и токенов в реальном времени с автоматическим наложением блюра.
- **Локальная транскрипция (Whisper.cpp)**
  Генерация `.srt` и `.vtt` субтитров сразу после записи прямо на ПК пользователя, без отправки аудио в облако.
- **AI Summary и Таймкоды**
  Автоматическое разбиение видео на смысловые главы, генерация "Action Items".
- **Семантический поиск по видеобиблиотеке**
  Распознавание текста на экране (OCR) и поиск по словам из транскрипции по всей библиотеке записей.

## Фаза 3: Облака, Шеринг и Коллаборация (Q3 2027)
*Задача: Бесшовный опыт "Записал -> Отправил".*

- **Модульная система экспорта**
  Поддержка S3, Google Drive, OneDrive, Dropbox. Сценарий **Instant Share**: запись и транскрипция загружаются в облако, ссылка копируется в буфер обмена.
- **Легкий Post-Recording Редактор**
  Встроенный интерфейс обрезки (timeline), наложения стикеров, скрытия элементов с мгновенным выполнением через FFmpeg без перекодирования.

## Фаза 4: Enterprise, Стриминг и Экосистема (Q4 2027)
*Задача: Закрепление на корпоративном рынке.*

- **Трансляции (Live Streaming)**
  Поддержка протоколов RTMP/HLS для стриминга на YouTube, Twitch или локальные медиасерверы предприятия.
- **Архитектура расширений (Plugins)**
  Python API для сторонних плагинов (кастомные видео-фильтры, интеграции).
- **Service Mode**
  Запуск рекордера без GUI как службы Windows для автоматической видеофиксации работы серверов по расписанию.
