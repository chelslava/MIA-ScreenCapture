## Сценарий Прогона (30+ минут)

- [ ] Периодический `GET /health`.
- [ ] Периодический `GET /api/v1/status`.
- [ ] Периодический `GET /api/v1/config`.
- [ ] Минимум один цикл `POST /api/v1/start` -> `POST /api/v1/stop`.
- [ ] Минимум один `restart` API из GUI.
- [ ] После restart все базовые эндпоинты снова доступны.
- [ ] Во время прогона окно live-логов остается отзывчивым.
- [ ] Логи продолжают писаться без пропусков/ошибок записи.

## Быстрый Авто-Прогон (Опционально)

```bash
uv run python scripts/api_smoke_run.py \
  --base-url http://127.0.0.1:5010 \
  --api-key <TOKEN> \
  --duration-minutes 30 \
  --interval-seconds 15
```
